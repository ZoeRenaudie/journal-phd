### Notes

#### Mharion Cazaux – Drags et musées

Interventions dans les institutions (liste non exhaustive) :

- 2022 :
    - Université de Pau : Lecture de contes queer annulée (pression des parents).
    - Quai Branly : Exposition _« Black Indians »_ → Mauvaise organisation, espace majoritairement réservé aux VIP (peu respectueux du public).
- 2023 :
    - Rennes 2 : Intervention sur les drags.
    - Villa Arson : Exposition _« Before there were none »_ (sur Danielle Brathwaite-Shirley).
        - Avertissements : Exigés pour toutes ses expositions → Choque les équipes (ex. : _« Cet espace n’est pas le vôtre »_).
        - Message clé : Les musées se veulent inclusifs mais restent excluant·e·s (rappel nécessaire).
- 2024 :
    - Médiathèque d’Angoulême : Exposition.
    - Quai Branly : Soirée _« Mexico »_.
    - Musée d’Orsay : _« Dear King »_.
    - Musée Piscine (Picardie ?) : Concours drag.
    - Van Abbe Museum :
        - Queer Constituency : Groupe de visiteur·euse·s et salarié·e·s intervenant sur l’accrochage des collections.
        - Actions :
            - Création de vêtements portables pendant les visites.
            - Queer Book Club.
            - Texte : _« Queer Based Line »_ (publié en néerlandais).
    - Rémi Baert : _« Drag Clown Affair »_ → Les invité·e·s créaient des objets dans leurs personnages.
- 2025 :
    - Musée d’Histoire de Lyon.
    - Ville de Loupiac.
- 2026 :
    - Expositions-performances à Angoulême.

Constats :

- Intégration superficielle : Les drags sont toléré·e·s en événementiel (soirées, performances) mais absent·e·s des collections permanentes (ex. : MuCEM).
- Manque d’archivage : Peu d’artistes drag documentent leur travail.
- Tokenisation : Risque de réduire les artistes à leur identité (ex. : jury du prix Utopi.e critiqué pour son manque de diversité trans).

Solutions proposées :

- Former les équipes (commissariat, médiation).
- Veiller à la pluralité des représentations (éviter le whitewashing ou le pinkwashing).
#### Daisy Lambert – Archivage queer

- Focus : Intégration des traces drag dans les collections (ex. : photos au MuCEM).
- Enjeu : Comment conserver la dimension performative et éphémère des œuvres drag ?

### Lien avec la thèse

1. Drags et archives éphémères (Mharion Cazaux / Daisy Lambert)

- Problématique :
    
    - Les performances drag sont peu archivées (par les artistes comme par les institutions).
    - Piste pour ta thèse :
        - Documenter l’éphémère :
            - Capturer les processus (ex. : ateliers de création d’objets comme chez Rémi Baert).
            - Archiver les réactions du public (comment les performances drag sont reçues ?).
        - Intégrer les collections :
            - Comme au MuCEM (photos) ou au Van Abbe Museum (vêtements portables) → Comment rendre visibles des pratiques souvent invisibilisées ?
        - Dépasser l’événementiel :
            - Exemple : Le groupe « Queer Constituency » (Van Abbe) montre qu’il est possible d’intervenir sur les collections permanentes (accrochage, médiation).
- Outils concrets :
    
    - Queer Book Club → Documenter les discussions (comptes-rendus, enregistrements).
    - Avertissements (ex. : _« Cet espace n’est pas le vôtre »_) → Archiver les tensions entre institutions et communautés.

#### 2. Commissariat et décolonialité (Inès Geoffroy)

- « 100% L’EXPO » comme modèle alternatif :
    
    - Format : Exposition sauvage, hors les murs, centrée sur les artistes.
    - Documentation possible :
        - Transcrire les performances (ex. : texte de Kathy Acker lu par Anne-Sarah Huet).
        - Filmer les interactions (public, artistes, commissaires).
        - Archiver les objets créés in situ (ex. : vêtements, installations éphémères).
    - Thèmes à explorer :
        - Cryptage et adresse (Meryam Benbachir) → Comment documenter des œuvres qui refusent d’être "lues" par tou·te·s ?
        - Droit à la complexité (Emma Bert Lazli) → Éviter les catégories réductrices dans les notices.
- « La rhétorique du rideau » :
    
    - Concept clé : Visibilité choisie (vs. coming out imposé).
    - Application à la documentation :
        - Respecter les niveaux de partage : Certains artistes veulent montrer, d’autres cacher (ex. : Amine Habki sur l’intimité).
        - Archives "à rideaux" : Classer les documents selon leur degré de publicité (ex. : notices accessibles vs. archives réservées aux concerné·e·s).

#### 3. Institution vs. Communauté (Mharion Cazaux)

- Critique des musées :
    - Exclusion symbolique (ex. : _« Cet espace n’est pas le vôtre »_).
    - Tokenisation (ex. : prix Utopi.e critiqué pour son manque de diversité trans).
- Solutions pour ta thèse :
    - Former les équipes → Documenter les formations (comptes-rendus, supports pédagogiques).
    - Impliquer les communautés :
        - Co-écriture de notices (ex. : avec le groupe _« Queer Constituency »_).
        - Ateliers participatifs (ex. : restauration des patchworks avec Pascal Lièvre).
    - Évaluer l’impact :
        - Enquêtes post-exposition : Comment les publics queer et racisé·e·s ont-ils·elles vécu l’expérience ?
        - Suivi des artistes : Leur ressenti sur leur intégration (ou exclusion) des institutions.

#### 4. Langage et médiation (toutes les intervenantes)

- Alternatives aux notices classiques :
    - Textes collaboratifs (ex. : _« La Kate »_ d’Elena Lespes Muñoz).
    - Performances comme documentation (ex. : _« Seum »_ de Meryam Benbachir).
    - Fiction et scénarios (ex. : Collectif Les Paillettes).
- Pour ta thèse :
    - Expérimenter des formats hybrides :
        - Notices + performances (ex. : lire une notice comme un poème).
        - Archives sonores (enregistrements de lectures, comme à _100% L’EXPO_).
    - Documenter les silences :
        - Les annulations (ex. : contes à Pau) ou les censures (ex. : avertissements choquants) sont des traces à conserver.


### Idées principales

1. Les drags comme cas d’école pour la documentation queer :

- Problème : Éphémère vs. permanent → Comment archiver des pratiques performatives (drag, performances) ?
- Solutions :
    - Impliquer les communautés dans l’archivage (ex. : restauration des patchworks).
    - Créer des collections vivantes (ex. : vêtements portables au Van Abbe Museum).
    - Documenter les processus (ateliers, créations collectives) autant que les résultats.

2, Le commissariat comme acte politique :

- Inès Geoffroy montre qu’un·e commissaire peut :
    - Créer des espaces safe (ex. : _100% L’EXPO_).
    - Respecter les rythmes des artistes (ex. : _« La rhétorique du rideau »_).
    - Dénoncer les exclusions (ex. : _« Cet espace n’est pas le vôtre »_).
- Pour ta thèse : Analyser le rôle du·de la commissaire dans la production de savoirs queer.

3.Dépasser le tokenisme :

- Mharion Cazaux alerte sur :
    - L’intégration superficielle (drags en événementiel, mais pas dans les collections).
    - Le risque de catégorisation (ex. : prix Utopi.e).
- Pistes :
    - Exiger des quotas (représentation trans, racisé·e·s, etc.) dans les jurys et collections.
    - Former les équipes à l’intersectionnalité.

4. L’archivage comme acte de résistance :

- Daisy Lambert et Mharion Cazaux soulignent :
    - Les photos (MuCEM) et les objets (Van Abbe) peuvent matérialiser des histoires queer.
    - Mais : Il faut éviter de figer ces histoires dans des catégories institutionnelles.
- Idée : Créer des archives "fluides" (classements modifiables, notices évolutives).

4. Le langage comme outil de subversion :

- Meryam Benbachir : _« Être crypté·x·es »_ → Refus de la lisibilité forcée.
- Elena Lespes Muñoz : Écrire avec des moufles → Ralentir, introduire du hasard.
- Pour la documentation :
    - Accepter l’opacité : Certaines œuvres ne veulent pas être expliquées.
    - Multiplier les voix : Notices polyphoniques (plusieurs interprétations d’une même œuvre).

4. L’exposition comme espace de transmission :

- « 100% L’EXPO » et _« La rhétorique du rideau »_ montrent que les expositions peuvent être :
    - Des lieux de partage d’outils (stratégies de résistance).
    - Des espaces de famille choisie (artistes + public).
- À documenter :
    - Les discussions informelles (autour d’un barbecue, comme à Aubervilliers).
    - Les objets créés collectivement (ex. : vêtements, textes).
